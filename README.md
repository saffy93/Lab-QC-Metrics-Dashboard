# Lab-QC-Metrics-Dashboard



**Histology Quality Control Analysis with Pandas**



This dashboard analyzes daily QC metrics from the kind of high-volume CAP/CLIA-regulated histology lab I work in every day. I built it to show how I’m learning to use data analytics to track specimen volume, IHC slide counts, error rates, deviations, and turnaround times). These are the exact things I monitor during real-time QC checks every shift.



It demonstrates how I’m combining my 8+ years of hands-on lab experience (200+ specimens and 150+ IHC slides per day, training 10+ techs, handling deviations and CAPA) with data skills for future QA/QC and clinical data roles.



## Features

- Analyzes realistic daily histology QC data (specimen volume, IHC slides, errors, deviations, turnaround time)

- Calculates error rate %, deviation rate %, and throughput metrics

- Generates clear summary statistics and visualizations

- Built with the same tools used in regulated lab environments



## Technologies

- Python

- Pandas

- Matplotlib & Seaborn



## How to Run

1. Open `Lab_QC_Metrics_Dashboard.ipynb` in Google Colab

2. Run all cells

3. Modify the data dictionary to test your own lab metrics
